# Sprint_4

Проект содержит автотесты для класса BooksCollector.

Реализованы проверки:

- добавление новых книг;
- проверка некорректной длины названия книги;
- установка жанра книги;
- получение жанра книги;
- получение книг определённого жанра;
- получение словаря книг и жанров;
- получение книг, подходящих детям;
- добавление книги в избранное;
- удаление книги из избранного;
- получение списка избранных книг.

В проекте используется параметризация pytest.

Запуск тестов:

pytest -v tests.py
